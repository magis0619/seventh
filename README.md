# シナジーの塔（MVP）

1人称視点で塔を登り、ランダムなスキル付き装備を組み合わせて、ステータスを戦闘ごとに膨らませるローグライクです。

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173/  （デバッグパネル: ?debug=1 、シード固定: &seed=123）
npm test         # ユニットテスト（Vitest）
npm run build    # 型チェック + 本番ビルド（dist/）
npm run sim      # バランス検証用の自動プレイ（scripts/sim.test.ts、結果はコンソールに出力）
```

操作: `Space` / `Enter` で 進む・攻撃・スキップ、`Esc` で 戻る・逃げる。ドロップ画面は `1` `2`（装備）、`s`（倉庫）、`d`（捨てる）。

## 構成

```
src/
  data/   balance.ts（全バランス数値） skills.ts（24スキル） dungeons.ts（3つの塔） names.ts
  core/   描画に依存しない純粋な TS（rng / stats / skillEngine / itemGen / battle / run / save）
  ui/     scenes/（town, explore, battle, loot, result） corridor.ts（Canvas 疑似3D） format.ts（日本語単位） debug.ts
tests/    スキル24種・タグボーナス・トリガー連鎖と安全装置・§5.7 の噛み合い・抽選分布・ラン進行・セーブ
scripts/  sim.test.ts（自動プレイによるバランス検証）
```

## 仕様で決まっていなかった所の扱い（シンプルな方を選択）

| 項目 | 実装 |
|---|---|
| スキルが参照する値 | 「力」は素の力（武器攻撃を含まない）。「防御」「運」「最大HP」は装備込み。増加分は素のステータスに足す |
| タグボーナスの対象 | スキル自身のタグが伸ばすステータスへの加算にだけ掛かる（例: 魔力転換は魔タグだが「力」を伸ばすので対象外）。博打の倍化も対象外 |
| 反復 / 共鳴 | 反復 = 直前のスキルを**追加で**2回、共鳴 = 直後のスキルを追加で1回。「直前・直後」は装備をまたいだ全体の発動順で判定 |
| 攻撃時・被弾時スキル | スキルフェーズでは「待機」と表示するだけ。連撃・根性は持っているかどうか、反撃は個数分ダメージを返す |
| 連撃の追加攻撃 | 会心ではない通常ダメージ |
| 敵の速さ | 逃走率の計算だけに使う（敵の攻撃は1ターン1回） |
| 逃走率の下限 | 5%（式のままだと負になるため） |
| ボスから逃げた場合 | 階は突破扱いにならず、次の「進む」で同じボスと再戦 |
| 装備の入れ替え（ラン中） | 外した装備は続けて「倉庫へ / 捨てる / 別の枠に装備」を選ぶ |
| 武器が1本も無いとき | 倉庫にも武器が無ければ「拾った木の棒」を支給 |
| 初期装備 | 旅立ちの短剣（攻撃5）と旅人の外套（防御3・HP14） |
| 踏破後 | 開始階は 1 / 21 / 41 / 61 / 81F から選べる |
| 数値の上限 | 1e300 で打ち止め（double のオーバーフロー対策）。表示は 万〜無量大数、1e72 以上は指数表記 |
| ラン中のリロード | ランは保存しない（町の状態だけ保存） |
